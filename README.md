This project used MATLAB to analyze and experiment in finding the optimal bulb placement to maximize the light intensity in a room.

The code Bulb_300_Watt.m is used to find the optimal placement of a 300-watt light bulb in a room with the dimensions of length = 10m, width = 4m and height = 3m. The figure below shows where to place the 300 watt light blub to get maximum light intensity in the room of the given dimensions.
